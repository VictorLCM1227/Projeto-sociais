# 📱 Projeto Redes Sociais

Projeto desenvolvido durante o curso **HTML5 e CSS3**, do **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O projeto consiste na criação de uma página que simula uma interface de redes sociais, utilizando conceitos de **HTML5 e CSS3** aprendidos ao longo do curso.

## 🎯 Objetivo

O objetivo deste projeto foi colocar em prática os conhecimentos adquiridos durante o curso, especialmente na criação e estilização de páginas web.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3

## 📚 Sobre o projeto

Este projeto foi desenvolvido como parte dos exercícios práticos do curso de **HTML5 e CSS3 do Curso em Vídeo**.

Durante seu desenvolvimento, foram praticados conceitos como:

* Estruturação de páginas com HTML;
* Uso de elementos semânticos;
* Estilização com CSS;
* Trabalhos com imagens;
* Posicionamento de elementos;
* Layout e responsividade;
* Organização de arquivos de um projeto web.
